# LIJT Documentos

Site institucional estático para apresentar a atuação societária da LIJT e orientar escritórios e empresários até uma conversa comercial.

## Tecnologias

- HTML, CSS e JavaScript
- Vite para desenvolvimento e build

## Executar localmente

Use Node.js 20 ou superior:

```bash
npm ci
npm run dev
```

O terminal mostra o endereço local. Para validar a versão de produção:

```bash
npm run build
npm run preview
```

Os botões de contato abrem o WhatsApp com uma mensagem preenchida. A pessoa revisa e envia a mensagem no próprio WhatsApp; o site não mantém um backend nem armazena esses dados.
